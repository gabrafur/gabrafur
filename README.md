# Gabriel B. Furlan

Senior Data Engineer building scalable data platforms, distributed pipelines,
and reliable integrations with Databricks, PySpark, Python, SQL, and Azure.

I focus on the parts of data engineering that make systems dependable in
practice: clear contracts, idempotent processing, data quality, observability,
safe reprocessing, automated testing, and maintainable platform boundaries.

## Selected work

### [Customer Engagement Data Platform](https://github.com/gabrafur/customer-engagement-data-platform)

A production-inspired, end-to-end data engineering project built with fully
synthetic data. It demonstrates PySpark feature engineering, Delta Lake merge
semantics, configurable DAG orchestration, quality gates, deterministic
ranking, transactional outbox delivery, replay, reconciliation, CI, and tests.

**Stack:** Python · PySpark · Spark SQL · Delta Lake · Databricks Asset Bundles
· pytest · mypy · Ruff · GitHub Actions

### [My Smart Home](https://github.com/gabrafur/my_smart_home)

A continuously operated, self-hosted automation platform that integrates
Home Assistant, Node-RED, MQTT, Zigbee2MQTT, AppDaemon, custom Python services,
and Docker Compose. It highlights event-driven design, integration engineering,
observability, guarded upgrades, and recovery on constrained hardware.

**Stack:** Python · JavaScript · MQTT · Docker · Home Assistant · Node-RED ·
Zigbee2MQTT
